## Recommended pricing model

Use a **risk-neutral, common-factor Heston model of the observed CL futures curve**, with discrete arithmetic averaging matching AO. This is a proposed commodity adaptation, not a formula specified in the original meeting or an exchange-endorsed valuation method.

At valuation date t, initialize every required CL contract from its observed futures price F(t,T). Give all maturities the same proportional stochastic driver:

- dF(u,T)/F(u,T) = sqrt(v(u)) dW_F(u).
- dv(u) = kappa [theta − v(u)] du + sigma sqrt(v(u)) dW_v(u).
- Corr(dW_F,dW_v) = rho; v(t)=v0.

The five fitted quantities remain v0 (starting variance), kappa (mean-reversion speed), theta (long-run variance), sigma (volatility of variance), and rho (price/variance correlation). The observed futures curve, rate, strikes and averaging state are fixed conditioning inputs. No extra convenience-yield, curve-slope or discount-rate parameter is fitted. Equal proportional futures shocks are restrictive: maturity-specific shocks are absent, so conclusions concern this specified Heston adaptation.

Simulate joint future CL fixings at the actual averaging dates; do not apply the European vanilla Heston formula to AO. For N total fixings, the path average is [known fixing sum + simulated remaining fixings]/N. Discount the call or put payoff to obtain USD/barrel; multiply by 1,000 only for contract-dollar values. Known fixings include the valuation day's fixing for the retrospective EOD convention. Negative historical prices remain in the archive; the positive multiplicative baseline uses 2021–25 and maturities within 183 calendar days.

## Discounting default

**Development baseline:** deterministic, flat last-available SOFR, with ACT/360 daily compounding. D(t,T)=(1+r/360)^(-d), where r is decimal SOFR and d is calendar days. Heston variance time uses ACT/365F. Payment at expiry is an explicit approximation; premium/payment settlement lags still require contract confirmation.

We downloaded 1,742 official NY Fed SOFR observations. Availability is conservatively approximated by the next SOFR business date, using only a rate effective before the valuation date. Historical revisions and original publication vintages are not reconstructed.

A flat overnight rate is **not an observed OIS term curve**. Before attributing residuals to Heston, run rate/payment-lag sensitivity and compare with independent maturity-specific discount factors. CME describes SOFR OIS curve data; its legacy discount-factor FAQ covers 2008–2018 and directs post-2018 requests to Data Sales. The current SOFR Strip Rates page includes curve/term-rate offerings from March 2020, but term rates are not automatically discount factors. No current full-curve purchase or price is claimed.

AO call/put parity supplies a separate discount diagnostic: regress C−P against strike within one date/expiry; minus the slope estimates D. Keep this diagnostic separate from baseline rates because extracting D from the same target prices removes part of the error one is trying to measure. Model parameters are not vendor fields. Synthetic training labels must be generated by a tested Asian pricer using known parameter draws.

## Training and test periods

- **Train:** June 3–28, 2024: 19 observed dates, 16,453 prototype-complete option rows.
- **Test:** July 1–31, 2024: 22 observed dates, 18,254 prototype-complete option rows.
- **Fixed grid:** 34 coordinates from August/September/October 2024 contracts, $60–100 strikes in $5 steps, selected using >=80% June coverage only. June supplies 613/646 grid cells; July supplies 698/748. Missing cells remain null, never zero.

For the user's frozen-parameter transfer test, fit using June only, then freeze the five-parameter vector, preprocessing, search bounds, loss and surrogate weights before scoring July. A shared initial variance across daily snapshots is an explicit snapshot-benchmark assumption, not a sequential volatility filter. Update observed CL curves, rates and already-known fixings on each July date without fitting to July option labels. If volatility is updated by filtering, specify a separate past-only rule before testing.

The original manifold thesis asks a different question: how far is each day's vector from its nearest Heston-consistent vector? That requires optimizing parameters on that day's prices to measure projection distance; label it a separate experiment, not a frozen-parameter forecast. Surrogate simulation error must be benchmarked independently so it is not mistaken for Heston error. A conditional surrogate must receive the curve, time, discount and averaging state as well as parameters. Two months is a useful pilot; the full archive permits more time splits and robustness work.

The 1,311 observed fixed-grid cells require zero elapsed fixings, have no provisional required forward records, and have no missing discounts. Their averaging months start after both sample periods, which avoids using the unresolved terminal records as accrued-price inputs.

Dates are disjoint, but contracts and averaging exposures can span both months; this is not statistical independence or a causal trading-backtest claim.
