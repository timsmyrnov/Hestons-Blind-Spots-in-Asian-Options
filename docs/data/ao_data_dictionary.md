# Data dictionary and interpretation

All option premiums, futures prices, and strikes are USD per barrel. Multiply a payoff or quoted premium by 1,000 barrels for one contract. There are no bid/ask observations in this settlement archive. A Databento `actual` settlement flag is an exchange classification and does not establish an executed trade.

| Artifact | Grain and key | Interpretation |
|---|---|---|
| `ao_contracts.parquet` | One `contract_id` | `NYMEX:AO:YYYY-MM:C/P:strike(8 decimals)` is independent of reusable vendor symbols/instrument IDs. Includes roots, side, scale, units, multiplier, European/cash terms, first/last observed bounds and expiration evidence. Bounds are not activation dates. Latest explicit snapshot expiration/activation timestamps are retained where available; full historical daily validity and specification version history remain unverified/labeled. |
| `ao_observations.parquet` | One observation date / contract | Corrected latest-final retrospective settlement label. Contains original status/flags, source path/row, raw symbol and instrument ID, publication timestamp, ingestion timestamp, expiration and nullable OI/volume. Publication timestamp is the vendor capture proxy, not an exchange guaranteed publication time. Source originals retain earlier revisions. |
| `cl_futures_settlement_revisions.parquet` | Reference date / instrument / capture / action | Both CL and CSX, expiry-specific. `root` disambiguates. All retained non-intraday, non-trading-tick settlement revisions; negative CL values remain valid. Source file and capture timestamp preserved. |
| `cl_futures_settlements.parquet` | Reference date / canonical futures contract | Latest final preferred over preliminary; latest capture breaks ties. Contains CL and the explicitly labeled CSX validation series. This is not a back-adjusted continuous future. |
| `underlying_contracts.parquet` | Vendor instrument / symbol / contract / expiration | Actual historical monthly definition snapshots resolve full maturity year and expiry. CL raw symbols can be decade ambiguous; raw-symbol parsing is not used as an expiration substitute. |
| `ao_fixing_schedule.parquet` | Averaging month / fixing date | Normalized shared calendar. `ao_contract_fixing_bridge.parquet` supplies every AO contract -> averaging month. Nearby CL includes its expiry date. Historical dates are empirical exchange CL reference dates, checked against terminal CSX arithmetic average. Future weekdays are provisional, unpriced, and explicitly unverified. |
| `ao_fixing_state.parquet` | Observation date / averaging month | Known fixing count/sum, missing elapsed and remaining counts, cutoff, nearby CL price, calendar and availability masks. Cutoff is the earliest retained AO settlement capture in that date/month. Only reference dates <= observation date and revisions captured <= cutoff enter known fixings. |
| `ao_daily_research_panel.parquet` | Observation date / AO contract | Joins all the above state masks plus methodology regime and strike-shape diagnostics. Rates are null, never silently set to zero. `research_eligible` is conservative and requires a verified historical month calendar, available same-day CL curve, no missing elapsed fixings, a positive final unexpired option mark and no monotonicity/convexity flag. It is not evidence of liquidity, identifiability or statistical independence. |
| `ao_historical_sample.csv` | Source / date / option | Real source samples plus stress-date and recent API rows. Cross-source duplicates are intentional for reconciliation. Do not stack it on the canonical panel. |
| `ao_coverage_daily.csv`, `ao_coverage_by_expiry.csv` | Date; date/month | Exact records, strike/expiry/call-put counts, missing fields and eligibility. No complete daily listing denominator is claimed. |

`settlement_status` preserves preliminary, final, zero, negative, deleted and missing categories. `price_type` distinguishes actual/theoretical final exchange flags. Zero observations remain source facts and are excluded from positive-premium research vectors. Missing numeric fields remain typed nulls. `nominal_indicator` is null when not independently published in the selected data stream; a nominal previous close is never substituted for current settlement.

Statistics use the exchange reference date `ts_ref`; converting that midnight timestamp to Chicago time would shift it incorrectly. `publication_timestamp` is `ts_recv` converted to UTC. Volume and OI are retrospective descriptive fields with their own later publication behavior. Their information-availability time is NOT yet reconstructed; do not use them as causal features or claim all screening fields were known contemporaneously.

Rates, discount factors, Heston parameters, implied volatility surfaces and synthetic interpolated prices are not produced. CME daily bulletin nominal-close footnote describes the previous day's settlement. The parser reads the explicit SETT.PRICE column and retains raw row evidence. ClearPort's prior interest/volume columns remain explicitly prior-day, not current OI.

Research labels are revised historical settlements. A strategy backtest must additionally reconstruct the AO label available at its chosen clock time from preserved raw revisions. Fixing inputs alone are publication screened. Monthly definitions and empirical holiday calendars are retrospective reference reconstruction, not a proven historical metadata-availability feed.

`ao_contract_reference_versions.parquet` retains all 571,246 definition observations across 82 dated monthly AO snapshots. It resolves 38,590 of the 39,434 observed AO contract IDs explicitly. The remaining 844 use the separately flagged same-month expiration calendar, with exact per-contract definition timestamps unavailable. All explicit definitions report 1,000-barrel size and 0.01 display factor. The contract master now includes the most recent explicit expiration and activation timestamps, alongside the snapshot date; those are not claimed to be a daily point-in-time reference-data history.

Cross-source field audit found all 2,397 October 26 API OI values missing at the selected capture boundary, although the free final CME bulletin supplies them. Canonical observations therefore fill only missing current OI/volume from matching exchange samples, retaining the untouched `vendor_open_interest`/`vendor_volume`, field-specific source names, and exchange document/row references. They remain retrospective descriptive values with unknown liquidity publication timestamps. This is source-backed enrichment, not zero filling. All 10 independently comparable current OI values and all 83 comparable volumes agree exactly; the 2023 prior-day OI is not relabeled current. EOD-derived Greek fields retain exchange provenance and are not a newly calibrated volatility surface.

The strict research mask also excludes dataset-level degraded capture days and contracts lacking an explicit strike-level definition. Same-month expiration mappings remain in the observations with their evidence flag, but do not silently become fully verified research contracts. Unchanged price flags are descriptive diagnostics, not proof of stale or invalid marks. The needed remaining CL curve contracts must all be available at the cutoff.

## Actual underlying delivery and remaining blocker

Both approved statistics jobs are complete: 223,233 CL and 178,168 CSX date/contract records on 1,736 reference dates, November 29, 2019 through October 26, 2026. All 130 overlapping CL prices match CME's April 3, 2023 exchange file. All 166 monthly definition snapshots were downloaded. The combined quoted/receipted underlying acquisition is $4.702629 of existing credits, below the $6 approval. No repeat purchase is needed.

Expiry-day CL and CSX settlement messages lack the vendor final bit. The final-only fixing policy therefore leaves zero rows in the strict research-eligible subset. This is an explicit quality-policy restriction, not an absence of AO prices. Use `eligible_only=False` to inspect the downloaded native panel and masks. The updated clock/holiday-screened diagnostic reconciles 80 of 81 available CSX terminal prices within $0.00501/barrel. One stale-reference CL publication is quarantined, and two copied Good Friday prices are excluded as extra fixing dates. February 2020 remains unresolved; June 2020 lacks a terminal comparator. Raw originals and the original canonical outputs are preserved. The separate June/July 2024 pilot uses unseasoned August–October options: its required forward inputs carry final flags and no accrued fixing is required. See model_and_validation_defaults.md for the distinction between complete prototype inputs and broader validation.

The dataset supports descriptive settlement-surface work now. It is not yet an approved fully conditioned Heston calibration panel or a causal backtest. A further data purchase is not established as necessary; resolve the observed contract/flag differences first. Exact raw UTC nanosecond timestamps and source sequences are retained and used for publication ordering.


## Provisional model-input tables

`ao_calibration_inputs_provisional.parquet` supplies date/contract prices, known fixing state, forward completeness, SOFR source dates, calendar/variance horizons and a declared flat-SOFR discount factor. `prototype_input_complete` is a numerical-completeness screen; `fully_validated_calibration_ready` remains false. `ao_model_fixing_inputs.parquet` supplies contract-specific fixing identities, equal arithmetic weights, past known fixings and current forwards for future dates. It exposes no realized future fixing price. `model_defaults.json` records the pricing assumptions and five free Heston parameters. `pilot_june_july_2024/split_manifest.json` fixes the chronological split and training-only coordinate selection. These proprietary data tables are local, not committed.
